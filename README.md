# airline-booking-analysis

✈ Airline Booking Channel & Ancillary Revenue Analysis
📌 Project Overview

This project analyzes airline booking data to evaluate booking channel performance and ancillary revenue behavior. The goal is to identify patterns in customer booking behavior and uncover opportunities to improve upselling strategies.

🛠 Tools Used

MySQL (Data Analysis)

Tableau (Dashboard Visualization)

Excel (Data Cleaning)

🎯 Business Questions

Which booking channel drives the most bookings?

Do mobile users purchase more add-ons?

What is the distribution of trip types?

How does flight duration vary by booking channel?

📊 Key Insights

Internet remains the dominant booking channel.

Mobile users show higher ancillary purchase rates.

Round-trip bookings account for majority of transactions.

Longer flight durations correlate with higher preferred seat selection.
